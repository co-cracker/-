# 꼬꼬 아레나 — 멀티플레이 서버

오로라 계산 퀴즈 술래잡기. 계정 로그인 없이 **링크만 공유하면** 같은 방 이름으로 들어온 사람끼리 함께 플레이합니다.

## 파일 구조

```
kkokko-server/
├── package.json        ← 의존성 (express, socket.io)
├── server.js           ← 서버: 방·술래배정·오로라·문제출제·판정
└── public/
    └── index.html      ← 클라이언트: 3D 화면, 조작, HUD, 관리자 패널
```

`node_modules` 는 들어 있지 않습니다. 호스팅 서비스가 `package.json` 을 보고 알아서 설치합니다.

## 올리는 방법

### ⚠ Glitch 먼저 확인하세요

Glitch 는 2025년 7월에 **프로젝트 호스팅 서비스를 종료**했습니다. 계정 페이지는 남아 있지만 앱을 돌려주지는 않습니다.
아직 Glitch 가 쓸 수 있는 상태라면 아래 A 방법으로, 안 된다면 B 방법을 쓰세요. **코드는 어느 쪽이든 그대로입니다.**

### A. Glitch (아직 사용 가능한 경우)

1. glitch.com → **New Project → glitch-hello-node**
2. 왼쪽 파일 목록에서 기존 파일을 지우고, 위 3개 파일을 같은 이름으로 만들어 내용 붙여넣기
   (`public/index.html` 은 파일명을 `public/index.html` 로 그대로 입력하면 폴더가 생깁니다)
3. 저장하면 자동으로 설치·실행됩니다. **Share → Live site** 주소가 게임 주소입니다.

### B. Render (무료, 권장)

1. 이 폴더를 GitHub 에 올립니다 (비공개 저장소도 됩니다).
2. render.com → **New → Web Service** → 그 저장소 선택
3. 설정값
   - Environment: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
4. 배포가 끝나면 `https://○○○.onrender.com` 주소가 나옵니다.

> Railway, Replit, Fly.io, 학교·센터 자체 PC 어디든 똑같이 동작합니다.
> 필요한 것은 Node 16 이상뿐이고, 포트는 `process.env.PORT` 를 자동으로 씁니다.

### 내 컴퓨터에서 먼저 시험해 보기

```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000` 을 엽니다.
같은 와이파이의 다른 기기에서는 `http://<내PC아이피>:3000` 으로 들어옵니다.

## 아이들이 들어오는 방법

1. 선생님이 주소를 엽니다 → 이름 입력 → **방 이름**은 `main` 그대로 두고 들어가기
2. 아이들에게 같은 주소를 QR 이나 카톡으로 보냅니다
3. 아이들도 이름을 넣고 **같은 방 이름**으로 들어오면 끝입니다

방을 나누고 싶으면 방 이름만 다르게 하면 됩니다 (`1반`, `2반`).
주소 뒤에 `?room=1반` 을 붙이면 방 이름이 미리 채워집니다.

**가장 먼저 들어온 사람이 방장(👑)** 이 되고, 방장 화면에만 오른쪽 아래 **👑 관리** 버튼이 보입니다.
방장이 나가면 다음 사람이 자동으로 방장이 됩니다.

## 게임 규칙 (서버가 판정합니다)

| 항목 | 내용 |
|---|---|
| 맵 | 반경 152m 고정. 중앙에 오로라 1곳 |
| 오로라 | 기본 45초마다 열려서 30초 유지. 열린 동안에만 문제가 나옴 |
| 문제 | 덧셈·뺄셈·곱셈·나눗셈 자동 생성. 한 문제 5초 |
| 문제 후 | 정답·오답·시간초과 모두 **3초 무적**. 오로라가 닫힐 때도 전원 3초 무적 |
| 술래 | 매 라운드 무작위. **본인에게만** 알려주고 술래끼리도 서로 모름 |
| 무기 | 전원 똑같은 나무 몽둥이. 들었다고 술래가 아님 |
| 이름 | 평소 안 보임. **때리거나 맞는 순간에만** 이름이 뜸 |
| 점수 | 정답 +1 / 참가자가 술래를 잡으면 +3 / 술래가 참가자를 잡으면 +2 / 무고한 참가자를 치면 −2 / NPC를 치면 −1 과 3초 노출 |
| 탈락 | 부활 없음. 그 라운드는 관전. 관전자에게는 **술래가 빨갛게** 보임 |
| 종료 | 시간 종료, 참가자 전멸, 또는 술래 전멸 |

## 조작

- `W A S D` 이동 · 화면 드래그로 시점 · `Space` 휘두르기 · `1 2 3 4` 답 고르기
- 휴대폰은 왼쪽 아래 조이스틱과 오른쪽 아래 휘두르기 버튼

## 관리자(방장) 기능

오른쪽 아래 **👑 관리**
- 접속자 목록 (생존/탈락/점수 실시간)
- **전원 시작** — 모든 화면이 동시에 같은 설정으로 출발
- **중지** — 진행 중인 라운드 즉시 종료
- **강퇴** — 해당 화면만 잠금
- 라운드 시간, 오로라 간격·유지, 문제 제한, 술래 수, NPC 수, 이동 속도, 흐물 강도 조절
  (방장이 바꾼 값이 전원에게 그대로 전달됩니다)

## 기술 메모

- **서버 판정 방식**입니다. 점수·술래·탈락·문제 정답은 전부 서버가 가지고 있어서 브라우저를 조작해도 바뀌지 않습니다.
- 이동은 클라이언트가 보내되 서버가 **속도 상한(기본 속도의 3.2배)** 으로 잘라냅니다. 순간이동 치트가 막힙니다.
- 상태는 초당 15회 브로드캐스트하고 클라이언트가 보간합니다.
- 지형은 서버가 보낸 `seed` 로 모두가 **똑같이** 그립니다.
- NPC와 닭은 서버에서 한 번만 계산해 모두에게 같은 위치로 보냅니다.
- 한 서버에 방을 여러 개 둘 수 있고, 방이 비면 자동으로 정리됩니다.

### 동시 접속 인원

한 방 기준 **10~20명 + NPC 30명**이 무난합니다. 무료 호스팅에서는 NPC를 20명 아래로 낮추면 더 부드럽습니다.
